## Native widget details

Padding applies inside labels/buttons/panels; input/checkbox spacing should use margin. Height is unsupported on single-line inputs; it uses widget-native units elsewhere. Panel alignment positions its legend. Window defaults inherit to controls; avoid control-specific dimensions on window style. A property being supported does not promise pixel-perfect parity.

Native animation interpolates existing integer/hex color values; CSS animation presets/easing/transform properties are browser-only. TUI spacing is cell-based; it supports only the keys marked above. See [design guide](../design.md) for states, responsive breakpoints, tokens, precedence, reduced motion and security.
